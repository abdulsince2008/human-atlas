# Anatomy 360 — Project Status

- **Current Stage:** Pilot-Readiness Reset — **MBBS Anatomy Pilot** (Feature Freeze Active Pending External Educator & Student Validation)
- **Build Status:** `tsc --noEmit`, `oxlint app web` (0 warnings, 0 errors across 80 files), all 8 `npm run validate:*` checks, `40/40` unit tests across 8 suites (`education`, `presentation`, `graphics-pipeline`, `surgical-anatomy`, `tissue-materials`, `visualization-colors`, `dissection-registry`, `interaction-engine`), `npm test`, and `vite build` (`dist/`) all passing. Automated checks verify structural/referential integrity only — not medical accuracy.
- **Working Features:**
  - **Multi-Page Anatomy 360 Platform:** `Home`, `3D Anatomy` (`#/explorer`), `Present` (`#/present`), `Reference` (`#/systems`), `Learn` (`#/learn` — defaults to 12-system anatomy lessons), `Practical Lab` (`#/practical-lab`), `Study Dashboard` (`#/dashboard`), `Revision & Bookmarks` (`#/revision`, `#/bookmarks`), `Relationship Explorer` (`#/relationships`), `Physiology` (`#/physiology`), `Histology` (`#/histology`), `Clinical` (`#/clinical`), `Quizzes` (`#/quiz`), `Atlases` (`#/atlases`), `Search` (`#/search`), and `About` (`#/about`) using hash routing compatible with static hosting.
  - **Biomedical Curriculum Overview (`#/learn` → secondary tab, `app/education/`):** Introductory overview modules across 16 biomedical/clinical domains (17 modules total — introductory overviews, not completed courses), 5 learning tracks, 11 curriculum references (regulators, statutory frameworks, boards, and university examples), static 2D conceptual schematics with rendered pathway connections, verified BodyParts3D FMA 3D links, self-assessment MCQs, and honest asset-gap disclosures (`asset_missing` on Histology microscopy and Radiology imaging).
  - **Guided 3D Presentation & Clinical Mechanism Studio (`#/present`):** Reuses the existing `AnatomyScene` WebGL renderer with a deterministic `AnatomyPresentation` / `PresentationStep` engine (`app/presentation/`), **5 built-in scientifically grounded presentations** (3 clinical mechanism explainers — *Coronary Ischemia*, *Pituitary–Optic Chiasm Compression*, *Hepatic Portal Circulation* — plus *Cranial Dissection* and *Upper-Limb Surgical Education*), clinical-to-presentation deep linking, separate presenter narration & captions, embedded step knowledge checks, visual timeline authoring, `localStorage` persistence, validated JSON import/export, and browser-native local video recording (`HTMLCanvasElement.captureStream()` + `MediaRecorder` + DOM-mounted 2D composition canvas + optional microphone audio).
  - **3D Graphics, PBR, UV, Shadows & LOD Pipeline:** Merged-batch `DataTexture` WebGL shader with per-part PBR roughness/metalness (`partMaterialTexture`), triplanar UV generation (`app/graphics/uv-generator.ts`), 6 tileable linear-space procedural PBR micro-detail texture archetypes (`app/graphics/tissue-textures.ts`), `PCFSoftShadowMap` + cavity fill lighting, and real runtime LOD 0 (`2,288,268` tris) ↔ LOD 3 (`1,684,412` tris) hysteresis switching (`app/graphics/lod-manager.ts`, `public/models/atlas.lod3.json`).
  - **Scientific Accuracy & Dissection Hardening:** 10 core surgical dissection regions (`app/data/surgical-anatomy.ts`) with strict anti-bleed validation, 100 curated knowledge entries (97 `inModel: true`, 3 conceptual), 58 verified relationships, 12 canonical system lessons (28 topics), 4 interactive physiology evaluators (+ 1 planned endocrine spec), 10 clinical cases, 10 histology entries, 16 quiz questions, 15 curated external resources, and reconciled provenance/license registry (`FMA CUSTOM`, `TA2 CC BY-ND 4.0`, `BodyParts3D CC BY 4.0 / CC BY-SA 2.1 JP`, zero false `expert_verified` claims).
- **Known Limitations (Documented Honestly):**
  - BodyParts3D 4.0 provides an adult male reference only (`2,234` meshes, `3,432` FMA concepts); female reproductive anatomy, thyroid parenchyma, inner-ear cochlea, epicranial scalp muscles, falx/arachnoid/pia mater, upper-limb peripheral nerves, and staged embryological meshes are explicitly disclosed as conceptual/non-modeled where meshes are absent.
  - **Histology** (`asset_missing`) and **Radiology & Medical Imaging** (`asset_missing`) require openly licensed external microscopy slides and de-identified DICOM/X-ray/CT/MRI/ultrasound teaching datasets; no synthetic images are substituted as real clinical specimens or radiographs.
  - Pathophysiology presentations use healthy reference meshes with educational color highlights and explicit disclosures rather than fabricated pathological geometry.
  - All educational content remains in `draft` / `structured_reference` review states pending formal human medical-expert sign-off.
